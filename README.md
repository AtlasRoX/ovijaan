# ovijaan

**OBHIJAAN** — Personal Competition & Project Dashboard.

One account, one private workspace, one source of truth for competitions, hackathons, projects, and achievements.

## Features

- 🏆 **Competition Tracking**: Track hackathons, case competitions, and challenges with deadlines, stages, and submission requirements.
- 📁 **Project Management**: Manage ongoing and planned projects linked to competitions.
- ✅ **Task Management**: Prioritized action items and milestone checklists.
- 📅 **Calendar & Deadlines**: Overview of upcoming registration deadlines, submission dates, and judging rounds.
- 👥 **Team Coordination**: Track teammates, roles, and squad rosters.
- 🎖️ **Achievements & Vault**: Verifiable record of rankings, awards, and prize earnings.
- 🔒 **Secure Auth & Local-First**: Private session management with dual-layer offline fallback and zero public exposure.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.
